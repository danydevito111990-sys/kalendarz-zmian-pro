KALENDARZ ZMIAN PRO — PWA offline

Aby zainstalować: opublikuj zawartość katalogu pod HTTPS (np. Netlify), otwórz adres w Chrome na Androidzie, wybierz Zainstaluj aplikację / Dodaj do ekranu głównego. Po pierwszym załadowaniu PWA działa offline.

Nie instaluj z pliku content:// — Service Worker wymaga HTTPS lub localhost.

WAŻNE: Dane z poprzedniego pliku HTML w przeglądarce NIE przenoszą się automatycznie do nowego adresu. Najpierw wyeksportuj JSON w starej wersji, następnie zaimportuj go do nowej. Przed aktualizacją zachowaj kopię JSON. Nie usuwaj danych witryny i nie odinstalowuj aplikacji bez kopii.

APK: nie dołączono; wymaga środowiska Android SDK, budowy i podpisania pakietu.
